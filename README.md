## Open source

Local-first developer tools. They run on your machine, read your files, and make no network requests.

### **[Company OS](https://github.com/pickbitsai/company-os)** — a local ops dashboard for people running many projects with AI agents
Point it at a manifest and it generates a static company floor: what each project is, the commands it can actually run, which of those are load-bearing, and the live state of anything you've scheduled. Reads your `package.json` files at build time, so the command list can't go stale — it *is* your `package.json`. Optional panels cover docs, secrets, agent sessions, and project shape. MIT, no telemetry, no account, zero dependencies.

### **[enView](https://github.com/pickbitsai/enView)** — know what secrets live where, without exposing them
Scans every project for `.env` files and reports what's plaintext, what's gitignored, what's drifted between environments, and what's still sitting in git history after being deleted from disk. Values are never returned by any API — the local UI is the only place one is ever handled. `enview protect` exits non-zero, so it works as a CI or cron gate. MIT.

### **[Session Index](https://github.com/MrPickering/session-index)** — a local-first tracker for Codex and Claude Code sessions
Finds your agent sessions, copies the right resume command, and keeps your own names and notes across rescans. Meters seven-day utilization per engine so a routing plan is checkable rather than aspirational. Reads counts, models and timestamps — never prompt text.
